# OpenTech SLA Parameters and Minimum Acceptance Criteria

**Document ID:** SVC-001
**Status:** Active
**Version:** 1.0
**Last Updated:** 2026-10-08
**Owner:** Service Management

This document defines the minimum Service Level Agreement (SLA) parameters and acceptance criteria applicable to OpenTech technology services.

The service provider shall propose detailed SLA targets for warranty and post-warranty support periods.

**The SLA values provided herein are subject to negotiation with OpenTech, where applicable, prior to contract signing.**

| Area                | Parameter                  | Target SLA        | Acceptance Criteria                                           |
| ------------------- | -------------------------- | ----------------- | ------------------------------------------------------------- |
| System Availability | Production System Uptime   | ≥ 99.5% monthly   | Measured 24/7 excluding approved maintenance windows.         |
| System Availability | Planned Maintenance        | ≤ 4 hours/month   | Prior notification and approval required.                     |
| System Availability | Unplanned Downtime         | ≤ 3.6 hours/month | Total unscheduled downtime must not exceed the monthly limit. |
| Incident Management | Critical Incident Response | ≤ 30 minutes      | Provider must acknowledge and begin action within 30 minutes. |
